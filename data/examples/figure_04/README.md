# Figure 4 count-to-score examples

Use [three_input_metrics_example.tsv](three_input_metrics_example.tsv) to follow barcode counts through precision, recall and F1 for all three tools on ScTagger-S, ScTagger-L and the RAGE-seq lymph node. [three_input_metrics_recomputed.tsv](three_input_metrics_recomputed.tsv) contains the expected results.

[immune_reference_annotation_example.tsv](immune_reference_annotation_example.tsv) shows the T-cell, B-cell and T/B-doublet annotations used to define the lymph-node reference. The [Figure 4 guide](../../../docs/figure_04.md) gives both runnable examples.

[Columns and units](schema.json) describe the records; [source identities](provenance.json) identify the complete files and selected rows. The [complete result tables](../../../source_data/figure_04/) contain all 37 inputs.
