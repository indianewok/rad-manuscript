# Figure legends

**Figure 1. RAD workflow and computational efficiency.** A, schematic of RAD's read-layout parsing, barcode discovery, correction and demultiplexing workflow. B–C, total processing time and peak process memory for complete LongBench single-nucleus ONT (SN-ONT) and single-cell PacBio (SC-PB) inputs at 4, 16 and 64 tool threads, with three computational repetitions per condition. Total wall time is the sum of discovery and demultiplexing times within each repetition. Peak process memory is the larger GNU-time maximum resident set size across the two phases, converted from KiB to decimal GB. Summaries show means and sample standard deviations. D, spatial comparison of 16 µm Visium HD bins.

**Figure 2. Barcode discovery and physical-read assignment in synthetic data.** A, synthetic-data design and comparison of RAD, Flexiplex and BLAZE. B–C, barcode discovery assessed by exact true-positive, false-positive and false-negative barcode identities and the resulting precision, recall and F1. Quality-controlled inputs retain original read identifiers and nucleotide sequences while varying the stated quality conditions. D–H, native and corrected assignment performance, reported as physical-read counts and per-target read depth. Each input read is classified as native-correct, corrected-correct, native-incorrect, corrected-incorrect, excluded for multiple outputs, or unassigned. RAD excludes all multiply emitted physical identifiers; Flexiplex collapses repeated same-target assignments and excludes conflicting targets. Correction-only proportions exclude native assignments. Unselected targets remain missing in per-target comparisons rather than being converted to measured zero counts. Statistical significance determined by one-way ANOVA (****p < 0.0001).

**Figure 3. Supplied-list challenges and observed barcode-correction categories.** A–C, challenges using size-matched reference-excluded target lists for ScTagger-L, LongBench SC-ONT and the RAGE-seq cell-line mixture. Each tool receives the same input and target list within a replicate. Three list draws are technical randomizations. B, the percentage of all input physical reads assigned exactly once to the supplied target list, after excluding every multiply assigned identifier, including duplicate assignments to one target. The denominators are 4,993,805 ScTagger reads, 10,000,000 LongBench reads and 20,346,396 RAGE-seq reads. Raw assigned-read totals are also supplied. C, counts per supplied target barcode, retaining zero-count targets and the selected replicate-1 binding. Statistical significance determined by one-way ANOVA (****p < 0.0001). D–G, correction categories in four LongBench inputs. Corrected off-list denotes an observed source outside the complete chemistry catalog changed to a selected target. Failure Mode 1 denotes a catalog-valid source outside the matched filtered reference changed to a selected target. Failure Mode 2 denotes a reference-member source changed to a different reference-member target selected by the tool. Counts use unique original-read–target pairs within each category, including emitted RAD concatemer records. E, category totals. F, per-target category counts. G, category counts divided by all read–target pairs assigned to that target by the same tool. Categories can overlap and are not summed to obtain that denominator.

**Figure 4. Barcode discovery across 37 matched benchmark inputs.** A, the 37 selected inputs spanning experimental protocols, sample types and read architectures. B, matched positive-reference barcode counts. C–E, characteristics of the actual long-read inputs: read count, GC percentage and average Phred quality. F–H, per-input barcode-discovery F1, precision and recall for RAD, Flexiplex and BLAZE. I–K, their distributions across all 37 inputs, shown as box-and-whisker plots with medians and minimum-to-maximum whiskers. Statistical significance determined by the Friedman test.

**Figure 5. Benchmarking RAD performance on complex read structures.** A–F. Receptor-read recovery from the RAGE-seq mixture of Ramos B cells, Jurkat T cells and monocytes. A, input-cell composition. B–C, numbers of detected cells and their annotated identities for RAD, Flexiplex and BLAZE. D, BCR and TCR reads recovered by each tool. E–F, native and corrected-only read counts and per-barcode read depth by annotated cell population. Statistical significance by paired two-tailed t-test (****p<0.0001). G–H, RAD and FLAMESv2 processing of LR-Split-seq data. G, barcode recovery requiring identification of all three barcode components. H, long- versus short-read UMI counts per cell for the three annotated sample classes; dotted lines indicate x=y.

**Figure 6. Genotype recovery and cell-line annotation in LongBench single nuclei.** A, fixed Illumina UMAP of all 12,012 reference nuclei, including named singlets, doublets and unassigned nuclei. B, native tool genotype outcomes on the same fixed coordinates and reference populations; unselected barcodes remain distinct from selected but unassigned genotypes. Strict named-singlet recall uses all 5,782 reference named singlets as its denominator. C, total selected named-genotype nuclei by cell line, including selected nuclei outside the Illumina reference. Statistical significance defined by ANOVA with Dunnett’s multiple hypothesis correction.

**Figure 7. Differential-expression concordance with paired Illumina data.** The updated analysis uses the direct H146-versus-H526 contrast and 8,135 common eligible genes. A, intersections of same-direction Illumina-supported differential-expression calls. Both reference and tool calls require BH-adjusted P <0.05 and absolute log2 fold change >1. B, log2 fold change (H146/H526) versus −log10 common-family BH-adjusted P for each tool. ASCL1 and POU2F3 are indicated. C, uncapped confidence for BLAZE versus RAD or Flexiplex among directional Illumina-reference calls. D, directional F1 across nine adjusted-P and eleven absolute-fold-change thresholds for each tool; reference thresholds remain fixed at adjusted P <0.05 and absolute log2 fold change >1.
