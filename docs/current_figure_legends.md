## Revised legend text

**Figure 1. RAD workflow and computational efficiency.** A, schematic of RAD's read-layout parsing, barcode discovery, correction and demultiplexing workflow. B–C, total processing time and peak process memory for complete LongBench single-nucleus ONT (SN-ONT) and single-cell PacBio (SC-PB) inputs at 4, 16 and 64 tool threads, with three computational repetitions per condition. Total wall time is the sum of discovery and demultiplexing times within each repetition. Peak process memory is the larger GNU-time maximum resident set size across the two phases, converted from KiB to decimal GB. Summaries show means and sample standard deviations. D, intended spatial comparison for 16 µm Visium HD bins; this panel remains subject to the source-lineage hold described below.

Author review for Figure 1: the recovered HD count sources measure different stages (detection and demultiplexing). The selected detection totals and complete grid/tissue mask have been checked. Selected Seurat nCount_Spatial values and full barcode-to-bin creation provenance remain unresolved, so a validated shared-scale triptych and final artwork export are not available. Space Ranger here processes converted Nanopore data; it is not an independent Illumina reference. The timing and workflow source proofs do not certify this spatial panel.

**Figure 2. Barcode discovery and physical-read assignment in synthetic data.** A, synthetic-data design and comparison of RAD, Flexiplex and BLAZE. B–C, barcode discovery assessed by exact true-positive, false-positive and false-negative barcode identities and the resulting precision, recall and F1. Quality-controlled inputs retain original read identifiers and nucleotide sequences while varying the stated quality conditions. D–H, native and corrected assignment performance, reported as physical-read counts and per-target read depth. Each input read is classified as native-correct, corrected-correct, native-incorrect, corrected-incorrect, excluded for multiple outputs, or unassigned. RAD excludes all multiply emitted physical identifiers; Flexiplex collapses repeated same-target assignments and excludes conflicting targets. Correction-only proportions exclude native assignments. Unselected targets remain missing in per-target comparisons rather than being converted to measured zero counts. Statistical significance determined by one-way ANOVA (****p < 0.0001).

Author review for Figure 2: preserve the selected one-way ANOVA statement and significance annotations. Native Prism statistical settings and final load/save/export remain under review; the new source-data proofs do not reproduce or certify those annotations. The selected assignment inputs and target lists differ by workflow as documented in the Figure 2 guide; the comparison is not an identical-whitelist raw rerun.

**Figure 3. Supplied-list challenges and observed barcode-correction categories.** A–C, challenges using size-matched reference-excluded target lists for ScTagger-L, LongBench SC-ONT and the RAGE-seq cell-line mixture. Each tool receives the same input and target list within a replicate. Three list draws are technical randomizations. B, the percentage of all input physical reads assigned exactly once to the supplied target list, after excluding every multiply assigned identifier, including duplicate assignments to one target. The denominators are 4,993,805 ScTagger reads, 10,000,000 LongBench reads and 20,346,396 RAGE-seq reads. Raw assigned-read totals are also supplied. C, counts per supplied target barcode, retaining zero-count targets and the selected replicate-1 binding. Statistical significance determined by one-way ANOVA (****p < 0.0001). D–G, correction categories in four LongBench inputs. Corrected off-list denotes an observed source outside the complete chemistry catalog changed to a selected target. Failure Mode 1 denotes a catalog-valid source outside the matched filtered reference changed to a selected target. Failure Mode 2 denotes a reference-member source changed to a different reference-member target selected by the tool. Counts use unique original-read–target pairs within each category, including emitted RAD concatemer records. E, category totals. F, per-target category counts. G, category counts divided by all read–target pairs assigned to that target by the same tool. Categories can overlap and are not summed to obtain that denominator. These categories describe observed sequence changes and reference membership, not biological cell origin.

Author review for Figure 3: the complete matched RAGE replication and all nine input-identity/conservation checks passed. The selected source tables and data proofs use this new experiment. Preserve the selected one-way ANOVA analysis choice; the previous annotations are not certified for new RAGE results without recalculation and native artwork QA. Selected targets with no assigned pairs and unselected tool–target combinations have undefined percentages, not zero-percent measurements. Reference absence is an operational negative proxy, not proof of biological absence.

**Figure 4. Barcode discovery across 37 matched benchmark inputs.** A, the 37 selected inputs spanning experimental protocols, sample types and read architectures. B, matched positive-reference barcode counts. C–E, characteristics of the actual long-read inputs: read count, GC percentage and average Phred quality. F–H, per-input barcode-discovery F1, precision and recall for RAD, Flexiplex and BLAZE. I–K, their distributions across all 37 inputs, shown as box-and-whisker plots with medians and minimum-to-maximum whiskers. Statistical significance determined by Friedman Test.

Author review for Figure 4: the selected Friedman procedure and annotations remain unchanged. The 37 inputs include technical runs and repeated biological material and are not 37 independent biological replicates. ScMixology2 includes the documented retained-count/filter reconstruction. Biological reference sets are operational positive references rather than exhaustive negative truth. Read count, GC and quality are retained long-read SeqKit summaries, not matched short-read characteristics or a newly executed SeqKit analysis.

E–F, native and corrected-only read counts and per-barcode read depth by annotated cell population. Statistical significance by paired two-tailed t-test (****p<0.0001). G–H, RAD and FLAMESv2 processing of LR-Split-seq data. G, barcode recovery requiring identification of all three barcode components. H, long- versus short-read UMI counts per cell for the three annotated sample classes; dotted lines indicate x=y.
