## Figure 2

Figure 2. Benchmarking performance on synthetic data. A. Schematic of synthetic data used in performance evaluation and comparison of RAD (R, green), Flexiplex (F, light gray), and BLAZE (B, dark gray) in whitelist generation, demultiplexing, and analysis tasks. B-C. Whitelist generation performance. Quantitation of the true positive, false positive, and false negative barcodes generated by each method (B), and their resulting precision, sensitivity and F1 scores (C). D-E. Demultiplexing performance on native barcodes. Total read count (D), with false negative reads in red, and read depth (E) captured for native barcodes by each tool. F-H. Demultiplexing performance on error-corrected barcodes. The total number and proportions of correct and incorrect error-corrected read assignments were quantified (F). For correct (G) and incorrect (H) assignments, the upper panels show total read counts and the lower panels show reads per barcode for each tool. Statistical significance determined by one-way ANOVA (****p < 0.0001).

## Figure 3

Figure 3. Adaptive whitelisting provides high fidelity barcode identification and correction. A-C. Characterization of false positive barcode assignment rate. Using three datasets, random, size matched sets of “off-list” barcodes were provided as the whitelist to each tool and the rate at which reads were assigned to this list was assessed (A). Quantification of total read count (B) and read depth (C) assigned to false positive barcodes by each tool. Statistical significance determined by one-way ANOVA (****p < 0.0001). D-G. Barcode correction outcomes (D). Using the LongBench dataset, the total read counts (E), the read depth (F), and the percentage of reads per barcode (G) derived from corrected off-list or the two failure modes were quantified for each tool.

Failure Mode 1 (FM1) is correction from a cell-associated barcode in the matched filtered reference to a different reference barcode selected by the tool. Failure Mode 2 (FM2) is correction from a catalog-valid barcode outside the filtered reference to a selected barcode, representing the ambient/empty-droplet category. All three off-list datasets, including RAGE-seq, use the same list preparation, demultiplexing and physical-read counting procedure.

[Figure and methods](figure_03.md)

## Figure 4

Figure 4. High performance across diverse datasets and read architectures. Long read data generated from 37 samples were chosen from a variety of experimental protocols, sample types, and read architectures (A). Input characteristics are shown in B–E to illustrate the diversity of the datasets. This characterization included valid whitelist barcodes (B), total read count (C), GC content (D), and average Q (E). The long-read demultiplexing performance of each tool using RAD (R, green), Flexiplex (F, light grey), and BLAZE (B, dark grey), was characterized using F1 scores (F), precision (G), and recall (H) for all 37 samples. The distributions and medians of F1 scores (I), precision (J), and recall (K) across all 37 samples are shown as box-and-whisker plots, with whiskers indicating the minimum and maximum values.  Statistical significance determined by Friedman Test.
