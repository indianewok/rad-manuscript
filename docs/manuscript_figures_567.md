# Methods and results for Figures 5–7

## Methods

### Receptor-read recovery and LR-Split-seq

The RAGE-seq cell-line mixture ERR3268991 comprised Ramos B cells, Jurkat T cells and monocytes. Receptor assignments were joined to barcode assignments by original read identifier and to cell-type annotations by barcode. In the Flexiplex receptor checkpoint, native and corrected-only read counts were mutually exclusive: the source cumulative corrected column included native reads, which were subtracted once before reporting corrected-only counts. That receptor run used Flexiplex 1.02.5 with the 10x3v2 layout and flank-edit distance eight, and minimap2 2.26-r1175 with the map-ont preset and secondary alignments disabled against the TRUST4 human BCR/TCR reference.

The C2C12 LR-Split-seq library SRR13948564 contained 5,764,421 original reads and was paired with short-read library SRR13948565. Long reads were processed with RAD 1.0.2 at commit `b6853a3d3d1818130ac364f7937bd0690ae9e385` and the component-polyT workflow in FLAMES 2.7.1 at commit `bf2211a8da1e1c7327370ab12479ae70e1d37cd8`, containing Flexiplex 1.02.6. RAD used reverse-complemented component catalogs, [strict component acceptance](https://github.com/indianewok/rad/blob/b6853a3d3d1818130ac364f7937bd0690ae9e385/include/rad/sigstring.hpp#L3173-L3288), defensive correction, generated and whitelist edit distances two, chunk size 5,000 and four threads. The comparator [matched three barcode components separately](https://github.com/mritchielab/FLAMES/blob/bf2211a8da1e1c7327370ab12479ae70e1d37cd8/src/main-functions/flexiplex.cpp#L305-L362) with barcode edit distance one and buffer one, flank edit distance three, a ten-base UMI template and the terminal fixed eight-thymidine segment, with four threads and `reverse_complement=FALSE`. The [executed wrapper](https://github.com/indianewok/rad-manuscript/blob/90f819fde9bdf7cf72cb965ff9a9c386c9f588a7/source_data/figure_05/provenance/splitseq/component_runner.R#L67-L107) defines the read layout and processing call.

Published physical cells were matched to the saved Prism rows by cell ID. Cell identity combined the round-3 barcode, round-2 barcode and zero-based reverse-transcription well; the two reverse-transcription primer sequences from one well normalized to that well's T-primer sequence. Within each physical cell, distinct original read identifiers and exact UMI strings were counted from records with nonempty barcode and UMI. Summing per-cell read counts gives read–cell pairs, distinct from globally deduplicated source reads.

Per-cell read counts in the LR-Split-seq comparison were tested with a two-sided paired t-test, pairing the same physical cells between workflows.

### Cell-line genotype recovery in LongBench single nuclei

Cell-line identities in the LongBench single-nucleus ONT dataset were assigned after native tool-specific demultiplexing. The genotype comparison used RAD 1.0.2 at commit `920addacdbf40b815e13a146226e8f4b14a58aaf`, BLAZE 2.5.0, and the pinned Flexiplex 1.02.6 audit build. Each tool's native demultiplexed reads were aligned separately using [FLAMES 2.0.1](https://github.com/mritchielab/FLAMES/blob/4b6058f58c5b19365919990b3f2c1053f2035b01/R/minimap2_align.R#L42-L104) and minimap2 2.28-r1209 against GENCODE v44, with splice-aware alignment, secondary alignments disabled, annotation-derived junctions and seed 2023. [CellSNP-lite counting](https://github.com/youyupei/LongBench_workflow/blob/37a9506df7bcd92c488c0e4b2a5cbe09fa1fc19d/rules/sc_cell_line_anno.smk#L38-L62) used version 1.2.3 with CB/UB tags, minimum allele frequency 0.1 and minimum count ten; [Vireo assignment](https://github.com/youyupei/LongBench_workflow/blob/37a9506df7bcd92c488c0e4b2a5cbe09fa1fc19d/rules/sc_cell_line_anno.smk#L65-L88) used version 0.5.8 with genotype input and ambient-RNA estimation. All tools used the same fixed eight-cell-line bulk-Illumina genotype panel. Identical duplicate VCF records were retained to preserve the executed panel and matrix row identities.

Strict identity recall was the number of same-cell-line named singlets recovered divided by all reference named singlets. Different-cell-line calls, doublets, unassigned cells and unselected barcodes remained in that denominator. Conditional concordance instead divided same-cell-line calls by same- plus different-cell-line named calls. The fixed UMAP and reference-outcome overlays used all reference-present barcodes. Figure 6C counts used **all tool-selected named genotypes**, including selected barcodes outside the Illumina reference.

The fixed Illumina coordinates came from the retained Seurat 5.4.0 object processed with SCTransform v2 using glmGamPoi. PCA used 50 components; neighbors used PCs 1–30; Louvain clustering used algorithm one and resolution 0.5. UMAP used PCs 1–30, 30 neighbors, minimum distance 0.3, cosine distance, seed 20260805 and one thread. Genotype calls were overlaid on these fixed coordinates.

### Differential cell-line expression in LongBench single nuclei

The expression comparison used RAD 1.0.2 at commit `4acbe004ba11b150d6832395452632f367a6e6c1`, BLAZE 2.5.0 native assignments and the pinned Flexiplex 1.02.6 diagnostic assignment sidecar. Common raw-read gene assignments were generated with minimap2 2.30-r1287 using splice-aware alignment, disabled secondary alignments, MD tags and soft-clipped supplementary alignments, without imposing a fixed read-strand orientation. Primary mapped alignments with MAPQ at least one were assigned to the gene with the largest summed unstranded overlap with annotated exon records; reads without exon overlap or with tied best genes were excluded. All emitted RAD records, including concatemer segments, were retained. Each emitted segment inherited its original read's frozen gene assignment. Exact cell–gene–UMI combinations were counted once; records without a UMI were counted individually.

The direct H146-versus-H526 contrast used positive-depth nuclei assigned to either cell line within each workflow. Gene eligibility required at least ten molecules and detection in at least 1% of the H146-plus-H526 cells within each platform. Gene eligibility sets were intersected across all four platforms. Counts were normalized to 10,000 per cell using full-library totals before gene filtering, then transformed as **log2(1 + CP10K)**. Two-sided scran Wilcoxon tests used serial execution. The effect estimate was log2[(mean H146 CP10K + 0.1)/(mean H526 CP10K + 0.1)]. BH adjustment was applied separately for each tool and the Illumina reference over the common gene family.

Illumina reference calls required BH-adjusted P <0.05 and absolute log2 fold change >1. Tool-supported calls additionally agreed with the reference direction. Directional F1 was 2TP/(2TP + FP + FN), with zero for a zero denominator. The threshold sweep used adjusted-P cutoffs of 10⁻⁸, 10⁻⁶, 10⁻⁵, 10⁻⁴, 0.001, 0.005, 0.01, 0.05 and 0.1, and absolute log2-fold-change cutoffs of 0.1, 0.25, 0.5, 0.75, 1, 1.25, 1.5, 1.75, 2, 2.5 and 3. Adjusted P values had to be below their cutoff, and absolute fold changes had to exceed theirs. Both expression directions were evaluated for each tool while the Illumina reference remained fixed. Confidence was the uncapped negative base-ten logarithm of the common-family adjusted P value.

## Results

Against 5,782 reference named singlets, RAD recovered 5,324 same-cell-line identities (92.08% strict recall), compared with 4,674 for Flexiplex (80.84%) and 4,450 for BLAZE (76.96%). All selected named-genotype nuclei, including those outside the reference population, totaled 9,404 for RAD, 7,125 for Flexiplex and 6,478 for BLAZE. [Reference outcomes](../source_data/figure_06/genotype_summary.tsv), [selected donor counts](../source_data/figure_06/selected_nuclei_by_donor.tsv).

Across 8,135 common eligible genes, the paired Illumina reference identified 1,181 differential-expression calls: 412 H146-high and 769 H526-high. RAD recovered 654 in the same direction (55.38% sensitivity), compared with 556 for Flexiplex (47.08%) and 522 for BLAZE (44.20%). Precision was 65.01% for RAD, 66.03% for Flexiplex and 63.43% for BLAZE. Signed log2-fold-change concordance with Illumina was Spearman ρ=0.6145, 0.5654 and 0.5487, respectively; uncapped confidence concordance was ρ=0.4427, 0.3974 and 0.3886. Thus, RAD recovered more reference-supported calls and showed higher rank concordance in this comparison, while Flexiplex had slightly higher precision. The analysis used each workflow's recovered cells at native depth.

In the selected LR-Split-seq comparison, RAD and component Flexiplex with poly-T recovered 2,078,171 and 1,156,252 read–cell pairs across the same 568 published physical cells; median per-cell read counts were 1,979.5 and 1,102.5. The corresponding exact cell–UMI counts were 1,891,704 and 1,050,292, with medians 1,866 and 1,042. Across the complete 5,764,421-read input, globally distinct assigned source reads were 2,498,488 (43.34%) and 1,338,285 (23.22%). These full-input distinct-read counts use a different denominator and deduplication scope from the paired per-cell comparison. [Selected counts](../source_data/figure_05/splitseq_reads_umis_568.tsv), [numerators and denominators](../source_data/figure_05/splitseq_summary.tsv).

## Rebuttal text

> We evaluated downstream differential-expression concordance in the LongBench SN-ONT H146-versus-H526 comparison using 8,135 genes eligible in all three workflows and paired Illumina data. At BH-adjusted P <0.05 and absolute log2 fold change >1, RAD recovered 654 of 1,181 Illumina-reference calls in the same direction, compared with 556 for Flexiplex and 522 for BLAZE. Sensitivities were 55.38%, 47.08% and 44.20%; precisions were 65.01%, 66.03% and 63.43%, respectively. Across all common genes, signed-effect Spearman correlations were 0.6145, 0.5654 and 0.5487, and uncapped-confidence correlations were 0.4427, 0.3974 and 0.3886. This comparison retains each workflow's positive-depth named H146/H526 cells and native depth. The updated RAD expression matrix retains all emitted concatemer segments under the documented original-read gene-inheritance and exact cell–gene–UMI counting rules.

The [figure legends](current_figure_legends.md) describe the panels. Detailed source records and executable workflows are in the [Figure 5](figure_05.md), [Figure 6](figure_06.md) and [Figure 7](figure_07.md) guides.
