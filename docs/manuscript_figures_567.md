### Figure 7: emitted segments, molecule counting and retained tests

The expression comparison used RAD 1.0.2 at commit `4acbe004ba11b150d6832395452632f367a6e6c1`, BLAZE 2.5.0 native assignments and the pinned Flexiplex 1.02.6 diagnostic assignment sidecar. This differs from the native alignment lineage used for Figure 6. Common raw-read gene assignments were generated with minimap2 2.30-r1287 using splice-aware alignment, disabled secondary alignments, MD tags and soft-clipped supplementary alignments, without imposing a fixed read-strand orientation. Primary mapped alignments with MAPQ at least one were assigned to the gene with the largest summed unstranded overlap with annotated exon records; reads without exon overlap or with tied best genes were excluded. All emitted RAD records, including concatemer segments, were retained. Each emitted segment inherited its original read's frozen gene assignment. Exact cell–gene–UMI combinations were counted once; records without a UMI were counted individually. The selected RAD matrix contained 22,875,174 molecules.

The direct H146-versus-H526 contrast used positive-depth named genotypes: RAD 709/419 cells, BLAZE 234/185, Flexiplex 290/219 and Illumina 263/195. Gene eligibility required at least ten molecules and detection in at least 1% of the H146-plus-H526 cells within each platform. The four pair-eligible sets intersected at 8,135 genes. Counts were normalized to 10,000 per cell using full-library totals before gene filtering, then transformed as **log2(1 + CP10K)**. Two-sided scran Wilcoxon tests used serial execution. The effect estimate was log2[(mean H146 CP10K + 0.1)/(mean H526 CP10K + 0.1)]. BH adjustment was applied separately for each tool and the Illumina reference over the same 8,135-gene family.

Illumina reference calls required BH-adjusted P <0.05 and absolute log2 fold change >1. Tool-supported calls additionally agreed with the reference direction. Directional F1 was 2TP/(2TP + FP + FN), with zero for a zero denominator. The threshold sweep evaluated nine adjusted-P cutoffs and eleven effect-size cutoffs in both directions for each tool, keeping the Illumina reference fixed. Confidence was the uncapped negative base-ten logarithm of the common-family adjusted P value.

These are the selected analysis methods. The current checkpoint validation retained the original Wilcoxon P values and independently recomputed BH adjustment, membership and threshold metrics; it did not rerun those tests. Every current raw P value and effect exactly matches the selected native direct-test table. The selected 57,885,606-row RAD emitted-assignment checkpoint has also been recovered and verified against its recorded hash, restoring original-read IDs, cell barcodes, UMIs, raw barcodes and correction flags. Its extractor had removed orientation/concatemer suffixes, and the table contains no gene IDs or segment coordinates. The emitted FASTQ and frozen read-to-gene file remain unavailable at the checked paths, so a complete gene/segment-boundary ledger or upstream replay is not claimed.
