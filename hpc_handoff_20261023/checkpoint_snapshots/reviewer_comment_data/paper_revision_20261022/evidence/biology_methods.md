The currently found mapping is an analysis input; its initial short-read annotation method is not documented here. The discovery reference has 4,505 barcodes, so it must not be silently equated with that 3,585-barcode identity map.
2. Figure 5 Flexiplex BCR/TCR rerun used 1.02.5, explicitly documented as a fallback, whereas whitelist discovery used 1.02.6. This panel cannot be described globally as entirely Flexiplex 1.02.6 without checking the actual figure source.
3. RAGE Flexiplex output columns named `corrected` contain **all** assigned reads, including native reads. RAD/BLAZE joins define `corrected` as corrected-only. The Flexiplex cumulative column must have native counts subtracted before plotting the exclusive classes described by the legend. The saved README explicitly documents this prior error.
4. A retained RAD RAGE rerun stderr contains `offensive: command not found`. Output tables exist, but the exact RAD version and successful command for those tables still require a provenance check. The intended wrapper alone is not proof of completed execution.
5. The Figure 5 LR-Split-seq comparator is called component-based FLAMESV2/Flexiplex with poly-T in the rebuttal. The exact final component-layout file, executed command and output-to-figure join were not found in the scoped evidence searched. Do not substitute MATCHED_SPLIT or a two-pass comparator. The short-read reference and 568-cell inclusion method are well documented.
6. Figure 6 post-demultiplexing genotype assignment and Figure 7 expression matrices use different alignment workflows. Genotypes use independently aligned demultiplexed FASTQs and FLAMES 2.0.1 genome alignment. Expression uses one common raw-read minimap2 alignment plus tool-specific barcode/UMI assignments. Describe both separately.
7. The exact completed RAD, Flexiplex and BLAZE CellSNP logs specify `--UMItag UB`. A graph-ready README incorrectly says `--UMItag None`. Executed commands take precedence.
8. The eight-line bulk genotype panel was reconstructed from independent bulk Illumina libraries. It contains 360,814 sites and reproduced all 12,012 released Illumina-SN hard calls. ### Immune receptor read assignment in the RAGE-seq cell-line mixture

The RAGE-seq cell-line mixture (ERR3268991) was used to compare barcode recovery and read assignment in cells with distinct immune receptors. Cell barcodes were linked to the reference Ramos, Jurkat and monocyte annotations. Barcodes without a reference cell-type annotation were classified as undetermined. [Confirm the source and initial method for the 1,993 Ramos, 1,572 Jurkat and 20 monocyte annotations, and the relationship to the 4,505-barcode discovery reference.]

Raw reads were aligned once to the TRUST4 human B-cell receptor and T-cell receptor reference, `hg38_bcrtcr.fa`, with minimap2 2.26-r1175 using `-x map-ont --secondary=no`. The reference contained 620 gene segments. The alignment with the largest number of matching bases was retained for each read. Reads assigned to immunoglobulin segments were classified as BCR reads. Reads assigned to T-cell receptor segments were classified as TCR reads. Reads without an alignment were classified as unmapped. The same read-level receptor classifications were used for all demultiplexers.

Final barcode assignments were joined to receptor classes by original read identifier. Reads assigned to more than one distinct barcode by a tool were excluded. Duplicate assignments to the same barcode were counted once. A read was classified as native if its observed barcode matched the final barcode without correction. The remaining assigned reads were classified as corrected. Native and corrected counts were mutually exclusive. Counts were summarized by barcode, reference cell type and receptor class. ### LR-Split-seq barcode and UMI analysis

The C2C12 LR-Split-seq library SRR13948564 (GSM5169183) was compared with its matched Illumina library SRR13948565 (GSM5169184) from GSE168776. ### Expression support for previously unassigned nuclei (include only if plotted)

Expression support was evaluated for the 6,171 nuclei that were unassigned by Illumina Vireo. The 5,782 named Illumina singlets served as labeled anchors; Illumina doublets were excluded from anchor training and rescue. A 25-nearest-neighbor classifier with inverse-distance weights and a nearest-centroid classifier were applied to the first 30 dimensions of the fixed Illumina principal-component space. A prediction required agreement between the two classifiers. Five repeats of stratified five-fold prediction generated out-of-fold anchor scores and query predictions. Consensus required at least three of five votes at each aggregation stage.

Anchors were divided by cell line into 2,888 calibration nuclei and 2,894 validation nuclei. For each predicted line, the acceptance threshold maximized the number of accepted calibration predictions while requiring at least 20 accepted predictions and an empirical positive predictive value of at least 95%. A 99% threshold was retained for sensitivity analysis. Thresholds were fixed before comparison with the long-read tool calls. A long-read named singlet was expression-supported when its cell-line assignment matched an accepted expression prediction. Rejected expression predictions remained unassigned and were not scored as incorrect. [Verify whether this analysis appears in Figure 6 or supplementary material.]

### Gene-count matrices and differential expression in LongBench nuclei

The raw LongBench single-nucleus ONT reads were aligned once to the GENCODE v44 GRCh38 primary assembly with minimap2 2.30-r1287 using `-ax splice --secondary=no --MD -Y`. No fixed read-strand orientation was imposed. Primary mapped alignments with mapping quality of at least one were retained. Each read was assigned to the gene with the largest summed overlap between aligned blocks and annotated exon records, without a strand restriction. Reads with no exon overlap or a tie between the two highest-scoring genes were excluded.

The common read-to-gene table was joined to each tool's barcode and UMI assignments. Identical cell-barcode, gene and UMI combinations were counted once. Records without a UMI were counted separately. The RAD matrix was rebuilt from all records emitted by commit `4acbe004ba11b150d6832395452632f367a6e6c1`, including concatenate-derived segments. Each such segment inherited the gene assigned to its original physical read. The Flexiplex matrix likewise retained its emitted split and multi-target records.

Differential expression used all positive-depth nuclei assigned by Vireo to the cell lines in each contrast. Doublets and unassigned nuclei were excluded. For the direct H146–H526 comparison, gene eligibility was defined separately for each tool: at least 10 counted molecules across the two cell lines and detection in at least 1% of their positive-depth nuclei. Counts were normalized to 10,000 molecules per nucleus using the complete, unfiltered library size and transformed as `log2(1 + normalized count)`. A two-sided Wilcoxon rank-sum test was applied with `scran::pairwiseWilcox`. P values were adjusted by the Benjamini–Hochberg method within each tool and contrast. Log2 fold change was calculated from the ratio of mean normalized H146 and H526 counts, with 0.1 added to each mean. Positive values indicated higher expression in H146. [Native effect-qualified calls used FDR <0.05, absolute log2 fold change ≥0.5 and detection in ≥10% of either group; confirm whether this rule supplies the Venn diagram.]

Benjamini–Hochberg adjustment was recalculated within this common gene set for every dataset. Reference differential-expression calls required Illumina FDR <0.05 and a directional absolute log2 fold change greater than one.
