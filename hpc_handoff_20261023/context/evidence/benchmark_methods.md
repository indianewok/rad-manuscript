### Suggested Methods prose: use the parts that match the final figure

**Synthetic benchmark and reference assignments.** The ScTagger synthetic datasets were used to compare barcode discovery and read assignment. The small dataset contained 98,873 reads from 50 source barcodes. The large dataset contained 4,993,805 reads from 5,000 source barcodes. The source barcode encoded in each read identifier defined the reference barcode. Barcode discovery was evaluated by exact set comparison between the selected whitelist and the reference barcode set. A true positive was a selected reference barcode. A false positive was a selected barcode outside the reference set. A false negative was a reference barcode absent from the selected whitelist. Precision was TP/(TP+FP), recall was TP/(TP+FN), and F1 was 2TP/(2TP+FP+FN).

Read-assignment accuracy was evaluated separately from whitelist accuracy. The final assigned barcode was compared with the barcode encoded in the read identifier. Native assignments retained the extracted barcode without correction. Corrected assignments changed the extracted barcode. An assignment was correct only when the final barcode matched the reference barcode. For strict physical-read analyses, tool-specific orientation suffixes were removed before grouping records by input read identifier. A read with more than one emitted assignment was classified as ambiguous and excluded from native, corrected, and incorrect counts. Reads with no assignment were classified as unassigned. [Use this strict paragraph only for panels actually sourced from strict analysis. Older Prism tables can be record-level.] Fixed-whitelist experiments supplied the same 5,000 reference barcodes to each tool and were evaluated separately from experiments using tool-selected whitelists.
