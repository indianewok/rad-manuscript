RAD manuscript, R workspaces for figure generation

Authors/Creators

  • Vaidya, Chinmay M.1
  • 1. Geisel School of Medicine at Dartmouth

Description

R workspace files (.RData) containing all intermediate and final analysis objects used to produce Figures 2–5 of the RAD manuscript (https://www.biorxiv.org/content/10.64898/2026.05.29.728810v1.full).

Each figure_N_workspace.RData corresponds to one figure and is consumed by the matching R Markdown notebook in the companion GitHub repository indianewok/rad-manuscript.

Loading a workspace restores all named objects referenced by the figure's Rmd, allowing the figures to be rendered without the underlying raw FASTQ data. Per-workspace contents are documented in data/README.md of the GitHub repo.
