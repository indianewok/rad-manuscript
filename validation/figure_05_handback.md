# Figure 5 validation

The LR-Split-seq checks reproduce the per-cell read and UMI counts from the complete RAD ED2 and component Flexiplex/poly-T assignment ledgers. The [Figure 5 guide](../docs/figure_05.md) gives the methods, commands and source tables.

## Source identity

The [package receipt](figure_05_incoming_review.json) verifies all 180 listed files against their original hashes; the complete package contains 181 files including its checksum manifest. The [source manifest](../manifests/figure_05_splitseq_sources.tsv) records paths, sizes, hashes and selected fields.

Cell identities also match the independent short-read reference. The [recovery report](figure_05_splitseq_recovery.json) records these comparisons.

The [native Prism check](figure_05_native_stat_review.json) verifies the master archive hash (`2987ae97728ff61488a861b305aa2b9fb356f51ba860c084e9c06c823765572b`), selected datasets, graph links and stored statistical analysis.

## Statistical and percentage checks

The saved two-sided paired t-test uses 568 physical-cell pairs: t = 14.959474687143327, df = 567 and P = 6.890554214980993e-43. Independent calculation agrees within floating-point rounding.

For the component workflow, globally distinct full-input reads give 1,338,285 / 5,764,421 = 23.22%. Assignment rows give 1,345,255 / 5,764,421 = 23.34%. These checks identify the earlier 23.35% annotation as a correction to make in the figure.
