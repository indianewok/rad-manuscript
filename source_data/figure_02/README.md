# Figure 2 source data

`discovery_metrics.tsv` contains 144 selected tool-condition rows: the 96-row Nanopore2018 S/L grid and 48-row Nanopore2023 L grid. FlatQ20 controls remain separate from heterogeneous quality transformations. All actual selected whitelists were independently rescored against retained S/L truth. `discovery_callset_manifest.tsv` records file hashes and origins; `discovery_barcode_identities.tsv.gz` contains every TP, FP and FN identity. This is barcode discovery, not read-assignment accuracy.

The paired quality sample contains 50,000 unique read IDs spanning all 5,000 L truth barcodes. `quality_summary.tsv`, `reconstructed_full_quality_histograms.tsv` and `matched_quality_levels.tsv` retain the per-base transform evidence: sample means/SDs, full-base conservation and eleven matched whole-dataset means were independently checked. Per-base clipping cannot be reconstructed from averaged barcode qualities. The historical `sample_replay_evidence.jsonl.gz` is absent at the checked recorded path, so this package does not claim a fresh generator replay.

`assignment_six_states.tsv` partitions all 4,993,805 physical reads for each tool. RAD excludes any ID with multiple output records. Flexiplex collapses same-target duplicates and excludes IDs with different final targets. BLAZE matcher ambiguity remains unassigned. `assignment_per_target.tsv` has explicit selected/truth flags; unselected targets have blank counts. The independent reconstruction from every retained read-level record matches all 52,076 selected-target category values; its equality/hash receipt is retained without depositing a duplicate table. The command and complete source hashes are in `validation/figures_124_assignment_resume.json`.

`correction_only.tsv` uses corrected-correct + corrected-incorrect as denominator. Native errors, multiple-output exclusions and unassigned reads are outside this denominator. BLAZE has 15 extra selected targets, with 908 incorrect corrections and 183 native incorrect assignments. Incorrect corrections restricted to truth targets exclude those 908 events.

`quality_generation_contract.json` records distinct S/L base seeds, literal model paths and effective quality-tape seeds. Model bytes and model pathname both contribute to historical identity; the source generator remains unchanged. A completed `validation/figures_124_fastq_identity.json` independently verifies full retained input bytes, unique IDs, truth counts, ordered sequences and native quality identity. This verifies inputs, not tool execution from raw FASTQ.

The immutable corrected Prism source remains outside the repository because its whole project includes unrelated and superseded sheets; only current canonical tables/plots are published. See `desktop_QA.md`: data consistency, structural checks and native rendering are separate gates. Existing statistics/annotations are preserved. Native authoring of a clean current project and native inspect/save/export remain unavailable on HPC. Review renders include no unsupported significance annotations.
