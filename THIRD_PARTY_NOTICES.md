# Included software

`vendor/flexiplex-audit` contains Flexiplex source at upstream commit
`d84c8ae4f3865052f2b5ecec816949b94682f302`, a local diagnostic patch, and Edlib
1.2.7 source. Their original MIT license texts and copyright notices are retained
in that directory's `licenses/` folder. The repository's license does not replace
those notices. The diagnostic patch exposes the already extracted raw barcode;
its exact source and build identity are described in the vendor README.

The selected LR-Split-seq producer snapshots in
`source_data/figure_05/provenance/splitseq/` include FLAMES code at commit
`bf2211a8da1e1c7327370ab12479ae70e1d37cd8`. Its supplied package description
declares GPL version 3 or later. The embedded Flexiplex source separately
declares the MIT license. The included descriptions, source notices and license
texts preserve those distinctions; the manuscript repository's MIT license
does not replace them.

The manuscript analyses use RAD, BLAZE and Flexiplex. Their run-specific versions,
commands and citations belong to the individual figure walkthroughs. External
reference data retain their original access and attribution conditions, recorded
in the dataset and input manifests.
